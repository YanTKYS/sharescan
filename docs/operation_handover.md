# sharescan 運用引継ぎマニュアル

**対象読者**: 運用担当者（情報システム担当職員）

---

## 1. このツールでできること

- 指定した共有フォルダ配下を自動で走査し、棚卸レポートを生成します
- 以下の情報を収集・可視化します：
  - **大容量ファイル**: ストレージを多く占有しているファイルの一覧
  - **重複ファイル候補**: 同一内容のファイルが複数箇所に存在する候補
  - **長パス候補**: パス文字数が多く、移行・バックアップ時に問題になりやすいファイル
  - **古いファイル候補**: 長期間更新されていないファイルの一覧
  - **拡張子別集計**: ファイル種別・容量の全体像
  - **走査エラー**: アクセス拒否等のエラーの記録

---

## 2. このツールでできないこと

> **重要**: 以下の操作は本ツールでは一切行えません。これは意図的な設計です。

- ファイルの削除
- ファイルの移動・コピー
- ファイルの名前変更
- アクセス権の変更
- ファイル内容の閲覧・編集
- ファイルサーバへの書き込み

本ツールは **読み取り専用** のツールです。レポートはあくまで棚卸情報の提供であり、実際の整理作業は人間が判断して行ってください。

---

## 3. 実行前の確認

| 確認事項 | 内容 |
|---------|------|
| 実行権限 | 対象フォルダへの読み取りアクセス権があること |
| 空きディスク容量 | 出力フォルダに十分な空き容量があること（通常数MBで十分） |
| 対象フォルダパス | UNCパス（`\\server\share`）またはローカルパスが正確であること |
| 設定ファイル | `config.json` の内容を事前に確認・修正すること |

---

## 4. 実行手順

### 手順 1: ツールの配置

`sharescan.exe` を任意のフォルダに配置します。

### 手順 2: 設定ファイルの作成（任意）

`config.sample.json` をコピーして `config.json` を作成し、対象フォルダを設定します。

```json
{
  "targets": [
    "\\\\server\\share1"
  ],
  "outputDir": "output",
  "largeFileThresholdMB": 100,
  "longPathThreshold": 240,
  "oldFileYears": 5,
  "enableHashDuplicateCheck": true,
  "maxRowsInHtml": 100
}
```

### 手順 3: 実行

コマンドプロンプトを開き、以下のいずれかを実行します。

**直接指定する場合:**
```
sharescan.exe "\\server\share"
```

**設定ファイルを使う場合:**
```
sharescan.exe --config config.json
```

### 手順 4: 進捗確認

実行中は標準出力にログが表示されます。完了すると以下のようなサマリーが表示されます。

```
=== 走査結果サマリー ===
走査日時      : 2024-04-01 10:30:00
総ファイル数  : 12,345 件
総フォルダ数  : 678 件
総容量        : 45.2 GB
大容量ファイル: 23 件
重複候補      : 5 グループ
...
レポート出力先: output
```

### 手順 5: レポート確認

`output/report.html` をブラウザで開いてレポートを確認します。

## 5. レポート確認方法

### report.html の見方

ブラウザで開くと、以下のセクションが表示されます。

| セクション | 確認ポイント |
|-----------|------------|
| 1. 概要 | 総ファイル数・容量・各種候補件数の概況を把握 |
| 2. 対象フォルダ | 走査した対象フォルダが正しいか確認 |
| 3. 大容量ファイル | 容量を多く占有しているファイルの確認 |
| 4. 重複ファイル候補 | 同一内容ファイルのグループを確認 |
| 5. 拡張子別集計 | ファイル種別の分布を確認 |
| 6. 長パス候補 | パスが長すぎるファイルを確認 |
| 7. 古いファイル候補 | 長期未更新ファイルを確認 |
| 8. 走査エラー | アクセスできなかったフォルダ・ファイルを確認 |
| 9. 注意事項 | 取扱い上の注意を確認 |

### CSVの使い方

各CSVはExcelで開けます。並び替えやフィルタリングで詳細を確認できます。

- `large_files.csv`: サイズの大きい順に並んでいます
- `duplicate_files.csv`: グループ番号でフィルタすると同一グループが確認しやすいです
- `extension_summary.csv`: 容量の多い拡張子順に並んでいます

---

## 6. 重複候補の扱い方

重複ファイル候補は**機械的な判定結果**です。以下の点に注意してください。

1. **内容が同じでも、残すべきファイルが存在する場合があります**（バックアップ、異なる保存先での保管など）
2. **削除を行う前に、業務所管部署が内容・用途を確認してください**
3. **本ツールでは削除できません**。削除が必要と判断した場合は、別途手動で実施してください
4. 重複候補の削除判断は、必ず複数人で確認することを推奨します

---

## 7. レポート取扱注意

レポートにはファイルのパス・ファイル名が含まれます。

- 個人情報が含まれるフォルダ名・ファイル名が表示される可能性があります
- 機密情報が含まれるディレクトリ構造が露出する可能性があります
- レポートファイルは取扱いに注意し、不要になったら適切に処分してください
- レポートを外部に送付する場合は、情報セキュリティポリシーに従って対応してください

## 8. トラブル時の確認事項

### ツールが起動しない

- Windowsの実行ポリシーやウイルス対策ソフトによってブロックされていないか確認
- コマンドプロンプトから直接実行してエラーメッセージを確認

### 「対象フォルダが存在しません」エラー

- パスのスペルを確認（UNCパスは `\\server\share` の形式）
- ネットワーク接続・VPN接続を確認
- フォルダへのアクセス権を確認

### 走査が完了しない・極端に遅い

- 大規模フォルダの場合、走査に時間がかかります（数十万ファイルで数分〜数十分）
- `excludeDirectories` で不要なフォルダを除外することで高速化できます
- `enableHashDuplicateCheck: false` にするとハッシュ計算を省略でき高速化できます

### report.html が文字化けする

- ブラウザのエンコーディングが UTF-8 になっているか確認（通常は自動判定）
- 別のブラウザで開いてみる

### CSVが文字化けする

- Excelで開く際に「データ」→「テキストファイル」から UTF-8 を指定して開く
- または LibreOffice Calc でエンコーディングを指定して開く

### scan_errors.csv にエラーが多数記録される

- アクセス権があるか確認
- ネットワーク接続が安定しているか確認
- システム管理者に権限の付与を依頼

---

## 9. 定期実行の推奨

共有フォルダの状況は時間とともに変化します。以下のタイミングでの実行を推奨します。

- ファイルサーバの移行前（現状把握）
- 年1回程度の定期棚卸
- ストレージ容量が逼迫したとき
- 組織改編・異動時の引き継ぎ前
