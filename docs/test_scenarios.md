# sharescan テストシナリオ

## 正常系

### T-01: 小規模フォルダを走査できる

**前提**: テスト用フォルダに数個のファイルを配置する

**手順**:
```
sharescan.exe "C:\test\share"
```

**期待結果**:
- エラーなく完了する
- `output/` にすべての出力ファイルが生成される
- 標準出力にサマリーが表示される

---

### T-02: config.json を使って走査できる

**前提**: `config.json` に対象フォルダを設定する

**手順**:
```
sharescan.exe --config config.json
```

**期待結果**:
- エラーなく完了する
- config.json の設定が反映されている（outputDirなど）

---

### T-03: 大容量ファイルが抽出される

**前提**: 100MB以上のファイルをテストフォルダに配置する

**期待結果**:
- `large_files.csv` に当該ファイルが記録される
- `report.html` の「3. 大容量ファイル」セクションに表示される

---

### T-04: 同一内容ファイルが重複候補になる

**前提**: 同じ内容のファイルを2か所以上に配置する

**期待結果**:
- `duplicate_files.csv` に重複グループとして記録される
- グループ番号・ハッシュ値・ファイルパスが記録される
- `report.html` の「4. 重複ファイル候補」セクションに表示される

---

### T-05: 同一サイズだが内容が違うファイルは重複にならない

**前提**: 同じサイズで内容が異なるファイルを配置する（`enableHashDuplicateCheck: true`）

**期待結果**:
- `duplicate_files.csv` に記録されない
- ハッシュが異なるため重複候補として抽出されない

---

### T-06: enableHashDuplicateCheck: false の場合はサイズ一致で重複候補になる

**前提**: 同じサイズで内容が異なるファイルを配置し、`enableHashDuplicateCheck: false` に設定する

**期待結果**:
- `duplicate_files.csv` にサイズ一致グループとして記録される
- ハッシュ値列は空（ハッシュ未計算）

---

### T-07: 長パスが抽出される

**前提**: `longPathThreshold` 以上の文字数を持つパスのファイルを配置する

**期待結果**:
- `long_paths.csv` に当該ファイルが記録される
- パス文字数が記録される

---

### T-08: 古いファイルが抽出される

**前提**: 最終更新日が `oldFileYears` 年以上前のファイルを配置する

**期待結果**:
- `old_files.csv` に当該ファイルが記録される
- 最終更新日時が記録される

---

### T-09: 拡張子別集計が出力される

**前提**: `.txt`、`.docx`、`.pdf` など複数拡張子のファイルを配置する

**期待結果**:
- `extension_summary.csv` に拡張子ごとのファイル数・合計容量が記録される
- 拡張子がないファイルは `(拡張子なし)` として集計される

---

### T-10: 除外ディレクトリが走査されない

**前提**: `excludeDirectories` に `.git` を設定し、`.git` フォルダを含む構造を走査する

**期待結果**:
- `.git` フォルダ配下のファイルは集計に含まれない

---

### T-11: 除外拡張子のファイルが集計されない

**前提**: `excludeExtensions` に `.tmp` を設定し、`.tmp` ファイルを含む構造を走査する

**期待結果**:
- `.tmp` ファイルは集計に含まれない
- 除外拡張子は大文字小文字を区別しない（`.TMP` も除外）

---

### T-12: report.html がブラウザで表示できる

**期待結果**:
- Internet Explorer、Edge、Chrome、Firefox いずれかで開ける
- 9つのセクションが表示される
- 文字化けがない
- 外部リソースへのアクセスなしで表示できる

---

### T-13: CSVがExcelで開ける

**期待結果**:
- 各CSVをダブルクリックでExcelが開く
- 日本語（ヘッダー含む）が文字化けしない（UTF-8 BOM）
- カンマや改行を含むパスが1セルに正しく収まっている

---

## 異常系

### T-14: アクセス拒否があっても処理が継続する

**前提**: アクセス権がないフォルダを含む構造を走査する

**期待結果**:
- ツールが途中で終了しない
- アクセス拒否エラーが `scan_errors.csv` に記録される
- アクセスできるファイルは正常に集計される
- 走査エラー件数がサマリーに表示される

---

### T-15: 存在しないフォルダを指定した場合にエラーメッセージが表示される

**手順**:
```
sharescan.exe "C:\not\exist\folder"
```

**期待結果**:
- わかりやすいエラーメッセージが表示される
- exit code 1 で終了する

---

### T-16: 設定ファイルが存在しない場合にエラーメッセージが表示される

**手順**:
```
sharescan.exe --config notfound.json
```

**期待結果**:
- わかりやすいエラーメッセージが表示される
- exit code 1 で終了する

---

### T-17: 不正なJSONを指定した場合にエラーメッセージが表示される

**前提**: 不正なJSON（例: `{ invalid }`）を設定ファイルとして指定する

**期待結果**:
- JSONパースエラーのメッセージが表示される
- exit code 1 で終了する

---

### T-18: 引数なし実行でヘルプが表示される

**手順**:
```
sharescan.exe
```

**期待結果**:
- エラーメッセージと使用方法が表示される
- exit code 1 で終了する

---

### T-19: ハッシュ計算エラーが記録されて処理継続する

**前提**: 走査中にファイルの読み取りが失敗する状況を想定する（テスト環境では再現困難な場合は記録のみ）

**期待結果**:
- ハッシュ計算失敗ファイルはスキップされる
- エラーが `scan_log.txt` に記録される
- 他のファイルの処理は継続する

---

## 自動テスト（`go test ./...`）

以下はGoの自動テストでカバーされているシナリオです。

| テストファイル | テスト内容 |
|--------------|----------|
| `config/config_test.go` | 設定ファイル読み込み、既定値適用、不正JSON処理 |
| `util/util_test.go` | サイズ表示変換、数値フォーマット、CSVエスケープ |
| `scanner/scanner_test.go` | ファイル走査、拡張子集計、大容量検出、重複判定、長パス、古いファイル、エラー継続 |
