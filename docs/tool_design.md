# sharescan ツール設計書

## 1. 背景

自治体の閉域ネットワーク内の共有フォルダには、長年にわたりファイルが蓄積されており、以下の課題が生じています。

- 大容量ファイルの所在が不明で、ストレージ圧迫の原因がわからない
- 同一ファイルが複数箇所に保存されているが、どこに何があるか把握できない
- パスが長すぎてバックアップや移行時にエラーが発生する
- 何年も更新されていない古いファイルが大量に残存している
- 拡張子別・容量別の状況が把握できず、整理の優先度がつけられない
- ファイルサーバの移行前に、現状の一覧化・可視化が必要

## 2. 目的

共有フォルダの現状を **安全に・非破壊的に** 棚卸・可視化する。

職員が自分で実行でき、ブラウザとExcelで結果を確認できるツールを提供する。

## 3. 対象範囲

- 指定したフォルダ配下の再帰的な走査
- UNCパス（`\\server\share`）を含むWindowsネットワーク共有フォルダ
- 読み取り可能なファイルとフォルダの情報収集
- HTMLレポートおよびCSVの出力

## 4. 対象外

- ファイルの削除・移動・リネーム・コピー
- アクセス権の変更・確認（権限エラーは記録のみ）
- ファイル内容の閲覧・テキスト解析
- ネットワーク帯域やアクセス速度の計測
- リアルタイム監視・スケジュール実行
- GUI（グラフィカルユーザーインターフェース）

## 5. 機能一覧

| 機能 | 説明 |
|------|------|
| フォルダ再帰走査 | 対象フォルダ配下を再帰的に走査 |
| 大容量ファイル検出 | 閾値（MB）以上のファイルを抽出 |
| 重複ファイル候補検出 | サイズ一致＋SHA-256ハッシュによる重複判定 |
| 長パス候補検出 | 指定文字数以上のパスを抽出 |
| 古いファイル候補検出 | 指定年数以上更新なしのファイルを抽出 |
| 拡張子別集計 | 拡張子ごとのファイル数・合計容量を集計 |
| エラー記録 | アクセス拒否等のエラーを記録し処理継続 |
| HTMLレポート生成 | ブラウザで閲覧可能な単一HTMLを生成 |
| CSV出力 | Excelで開けるUTF-8 BOM付きCSVを生成 |
| 設定ファイル対応 | JSONによる設定の外部化 |
| 除外設定 | ディレクトリ名・拡張子による除外 |

## 6. 安全設計

本ツールは以下の安全方針を厳守します。

- **書き込み操作ゼロ**: 走査対象のフォルダ・ファイルに対して一切の変更操作を行わない
- **削除機能なし**: ファイル削除のAPIやコマンドを実装しない
- **権限変更なし**: アクセス権・所有者の変更を行わない
- **エラー継続**: アクセス拒否や読み取り失敗があっても処理を継続し、エラーを記録する
- **出力先限定**: 書き込みは `outputDir` のみ（走査対象外）
- **外部通信なし**: インターネット接続を使用しない。外部サービスに情報を送信しない

## 7. 重複判定の考え方

### 判定アルゴリズム

1. **第1段階（サイズ一致）**: 全ファイルをサイズでグループ化し、同一サイズが2件以上のグループを候補とする
2. **第2段階（ハッシュ一致）**: `enableHashDuplicateCheck: true` の場合のみ、候補グループ内のファイルのSHA-256ハッシュを計算し、同一ハッシュのファイルを重複候補とする

### ハッシュを全ファイルに適用しない理由

- 大量ファイルへの全ハッシュ計算は時間・I/O負荷が高い
- サイズが異なれば内容が同一でないことは自明なので、サイズで絞り込んでから計算する
- 空ファイル（0バイト）はハッシュ計算対象から除外する

### enableHashDuplicateCheck: false の場合

サイズ一致のみで重複候補とする。ハッシュ計算を省略できるため、走査が高速になるが、同一サイズ・異内容ファイルも候補に含まれる。

### 「候補」という表記について

ハッシュが同一でも、ファイルの業務上の重複可否は内容を確認した上で業務担当者が判断する必要があります。ツールはあくまで機械的な候補を提示するにとどまります。

## 8. 出力仕様

### report.html

- 外部リソース（CSS/JS/CDN）を一切使用しない単一HTMLファイル
- 日本語フォント（Meiryo、MS PGothic）を指定
- 9つのセクションで構成（概要～注意事項）
- 各表はmaxRowsInHtml件に制限（超過時は注記を表示）
- 数値はカンマ区切り、容量は読みやすい単位（KB/MB/GB）で表示

### CSV

- UTF-8 with BOM（Excelで文字化けしない）
- ヘッダー行あり
- カンマ、改行、ダブルクォートを含む値は適切にエスケープ
- CRLF改行（Windows標準）

## 9. 今後の拡張候補

以下はv0.1.0では実装しない機能ですが、将来のバージョンで検討できる候補です。

| 候補機能 | 内容 | 注意点 |
|---------|------|--------|
| 差分比較 | 前回スキャン結果との差分を表示 | 削除・移動の推奨は行わない |
| Excel直接出力 | .xlsxファイルとして出力 | 外部ライブラリが必要 |
| 進捗表示 | 大規模フォルダ走査時の進捗バー | |
| フォルダ別集計 | フォルダ単位の容量・ファイル数集計 | |
| ファイル名検索 | 特定パターンのファイルを抽出 | |
| 定期実行ログ | 実行日時・対象を記録した実行履歴 | |

> **留意事項**: 将来バージョンでも削除・移動・リネームを自動実行する機能は追加しないことを推奨します。判断は常に人間が行うべきです。
